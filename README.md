# UET-mardan-chatbot
I built this chatbot to answer questions about UET Mardan using real data straight from the university's official website. It works by scraping the site's content, then using a RAG (Retrieval-Augmented Generation) setup to pull relevant info before sending it to Google's Gemini model for a proper, natural-sounding answer. The whole thing runs through a simple Streamlit app so anyone can just type a question and chat with it.
Tech stack: Python, Gemini API, RAG, Streamlit, BeautifulSoup
